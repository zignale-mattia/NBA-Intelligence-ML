# Before making the repository public

- [ ] Review all code for personal secrets, password output, and API keys.
- [ ] Replace hardcoded, obsolete Colab mount paths with configuration.
- [ ] Run a clean environment setup, collection, training and dashboard smoke test.
- [ ] Record real training/validation/test metrics and dataset date range.
- [ ] Verify prediction-time versus game-time anti-leakage checks.
- [ ] Confirm legal redistributability of any dataset or screenshot.
- [ ] Publish only the source and sanitized notebook, not SQLite/model files.
- [ ] Add a license if you wish to permit reuse.
- [ ] Validate scheduled automation separately from Colab uptime.
